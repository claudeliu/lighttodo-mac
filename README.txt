轻量待办 Mac 原生版 0.4.0

适用：macOS 12 或更新，Apple Silicon（M 系列）及 Intel。
解压后将 LightTodo.app 拖到“应用程序”，双击打开。
这是原生 AppKit 应用，不需要浏览器、.NET 或 Python，不联网。
首次启动空白，不含作者的私人待办、图片或设置。

输入待办，回车新增；勾选显示删除线，约 0.65 秒后进入完成记录。
搜索框可即时筛选当前的待办或完成记录；支持多个关键词，Command+F 可直接聚焦搜索。
完成记录不显示数量，悬停显示全文和时间；箭头可恢复为待办。
每条待办右侧的时钟可设置或取消本地提醒；完成待办会取消提醒。
程序关闭或电脑休眠时不能准时弹窗，重新打开后会补提醒；没有提醒时计时器停止。
链接图标可添加、打开、修改或移除 HTTP/HTTPS 网页及本地文件链接。
本地文件移动后原链接会失效；链接和提醒只保存在本机数据文件中。
右键待办或完成记录可复制文本并管理条目；删除非空待办、单条历史或全部历史前会确认。
菜单栏支持 Command+N 新增、Command+F 搜索、Command+1/2 切换列表、Command+Shift+P 切换置顶、撤销与重做，以及导入或导出本地 JSON 数据副本。
右上角图钉置顶、透明度和调色盘；调色盘可选底色、导入本地图片。
图片等比例铺满、卡片半透明；导入后压缩至最长边 1280 像素。
置顶高于普通窗口，不保证覆盖独占全屏游戏或系统安全窗口。
关闭最后一个窗口退出进程。无自启、无广告、无持续轮询。

数据保存在 ~/Library/Application Support/LightTodoNativeMac/
tasks.json 为明文数据，tasks.backup.json 为上次保存备份。
关闭后复制整个数据目录即可备份。与 Windows 版 XML 不通用。
窗口位置由 macOS 用户偏好保存。删除应用不会删除待办数据。

此试用版使用本地临时签名（ad-hoc），没有付费 Developer ID 及 Apple 公证。
若系统仅提示开发者无法验证，可在系统设置的“隐私与安全”中选择“仍要打开”。
不要关闭整个系统的安全防护。如果系统明确提示恶意软件或损坏，请先停止并反馈。

云端构建结果会提供自动测试记录，覆盖搜索、提醒、链接和数据导入。通过自动测试不代表全部 macOS 版本、输入法、显示器或游戏兼容性都已验证。
请反馈具体 macOS 版本、芯片类型和复现步骤；截图前遮住私人内容。
项目按 MIT License 开源，可免费使用和转发；不要连同个人数据目录一起分享。

新版操作：回车在光标处拆成下一条待办，Shift+回车在同条内换行。空白待办按退格/Delete或勾选直接删除，不进入历史。
每条完成记录右侧有恢复箭头，点击移回待办并从历史移除，不新增操作栏。
更新：退出旧版，将新版 LightTodo.app 拖到应用程序替换。原有数据保留。
卸载：退出后删除应用程序中的 LightTodo.app。若还要清除全部数据，在访达按 Shift+Command+G，输入 ~/Library/Application Support/LightTodoNativeMac，备份确认后删除该目录。
